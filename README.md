## Présentation

Eden est un annuaire qui regroupe des logiciels triés par usage : systèmes d'exploitation, retouche photo, illustration, création musicale, bureautique, IDE, compression, sécurité, navigation, et bien d'autres.

Le prix n'est pas un critère. Ce qui compte, c'est la qualité de l'expérience, l'absence de suivi, l'absence de publicité et le contrôle rendu à l'utilisateur. Un point rouge signale les logiciels commerciaux retenus malgré tout, parce qu'ils valent le détour.

Eden n'est pas un catalogue exhaustif. C'est une sélection exigeante, pensée pour celles et ceux qui veulent reprendre la main sur leur environnement numérique sans sacrifier le confort.

## Confidentialité

Eden ne collecte rien. Aucun cookie, aucun tracking, aucune requête externe, aucun compte. Le site est entièrement autonome et peut fonctionner hors-ligne une fois les fichiers téléchargés.
